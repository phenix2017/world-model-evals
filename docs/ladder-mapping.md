# L0–L7 与 M1–M5 映射

本仓库的 M 档位不是独立发明的标准，而是对世界模型研究中 L0–L7 分级的**压缩映射**，
用于把航天 V&V、大语言模型评测、世界模型评测放到同一把尺子上比较。

## 压缩关系

| 原始层级 | 含义 | 压缩后 |
|---|---|---|
| L0–L3 | 产物诊断 | **M1–M2** |
| L4–L6 | 决策证据 | **M3–M4** |
| L7 | 决策级可信 | **M5** |

分界线在 **M2 / M3** 之间：以下验的是「产物」，以上验的是「决策」。

## 五级定义

| 层级 | 名称 | 问的问题 |
|---|---|---|
| M1 | 看起来对 | 像真的吗？（真实感、流畅度、偏好投票） |
| M2 | 分项测得准 | 每一项对吗？（对照真值或明确规则逐项测量） |
| M3 | 系统级验证 | 证据链完整吗？（独立复核、需求↔测试可追溯、不确定度量化） |
| M4 | 决策级证据 | 敢拿它做决定吗？（评测结论能预测真实世界结果） |
| M5 | 认证与问责 | 谁签字？错了谁负责？（标准成文、第三方认证、合同门限） |

## 使用限制

- 这是**多对一**的概念映射，不是数学等价。
- L1 与 L3 被压进同一档，跨档进步在 M 尺度上可能不可见。
- 细节研究用 L0–L7；跨领域高层比较用 M1–M5，并必须同时公布映射表。
- **M1–M5 是本报告的分析框架，不是已确立的行业标准。**
